# Controlled Mutation Roadmap

## Philosophy

This is not blind randomization.

The goal is:

Reference -> Discovery

The system should preserve known safe anchors while allowing controlled risk, mutation, and sound discovery.

## Permanent Rule

Load anchors stay forever.

Capture does not replace anchors.

Capture lets the current hardware state become a temporary or saved anchor.

Validated anchors remain the safety net.

## Core System Concepts

- Validated anchors
- Captured anchors
- Mutation depth
- Mutation scope
- Pad/track locks
- Scene behavior
- Undo/redo
- A/B compare
- Mutation history
- Favorites / best discoveries
- Live-safe mode
- Studio-discovery mode

## Live-Safe Defaults

The tool should not touch by default:

- Master volume
- Track volume
- Clock
- Transport
- Pattern change
- Program change
- Project change
- Kit save/clear
- System commands
- Unvalidated SysEx writes
