What these numbers actually are

Every figure on this page comes from one measurement: an anonymous check-in. When the app checks for an update it also fetches a tiny per-version, per-OS marker file from the release, and GitHub increments that file’s download counter. Nothing else is sent — no identifier, no machine name, no telemetry payload.

Those counters are cumulative, so this page charts the difference between consecutive snapshots: how many check-ins arrived during each interval. To turn that into a device figure it divides by how often one device is expected to check in — once at launch and once every 4 hours while running, about times a day:

estimated devices = check-ins in the interval ÷ expected check-ins per device in the interval

That makes every device number an estimate, not a count. It is not a count of unique devices: a machine left running all day is indistinguishable from several machines used briefly, and a machine that is switched off contributes nothing. It cannot tell you that any particular machine is on any particular version. The raw check-in totals are the ground truth and are shown beside every estimate on this page.
