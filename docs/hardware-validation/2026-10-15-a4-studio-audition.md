# A4 Studio Audition - Supervised Scratch Procedure

Status: bounded software verification complete; physical observations NOT
PERFORMED. Do not use this as a show-ready receipt. The installed d563 rehearsal
delivery is unchanged and does not contain this new source-only studio flow.
Use an independently packaged and verified build of this exact integration
before testing. Preserve the old delivery and all original kit/audio files.

## Prerequisites

- Back up disposable Rytm and A4 kits using the instrument's established tools.
- Use a saved scratch A4 source slot, low monitoring level and direct USB.
- Confirm the output really belongs to the A4. The software requires an
  explicitly Analog Four-labelled OS output and refuses Rytm/generic labels;
  names alone cannot authenticate physical device or cable identity.
- Read the actual four synth-track MIDI channels on the A4. Enter those exact
  distinct 1..16 channels; there are no software defaults. Duplicate, unknown
  or generic DIN routes are outside this bounded trial.
- Confirm the existing input configuration permits CC reception from that USB
  route without disturbing OXI note/clock routing; sending to a port alone is
  not evidence that the instrument accepted the control.
- Preserve existing clock, note, pitch/tuning, OXI, kit selector, sample slot,
  master level and sequencer settings. Do not test a valuable show bank.

## First A4 Attempt

1. Start disarmed. Adopt backed-up paired saved-kit sources into a local cue.
2. Lock every Rytm pad and all A4 tracks except one. In the A4 parameter scope,
   select only a small supported change already audible in that source kit,
   such as Env2 Attack when that envelope is actively used. Generate a small
   native-fields candidate and select it in the active cue. If only front-panel
   value readback is demonstrable, record the listening result as inconclusive;
   do not change extra modulation/routing controls within this same trial.
3. Manually reload the immutable saved A4 source slot. Receive its current KIT
   through the input-only capture control. Confirm it matches the saved source;
   a saved-state dump alone cannot prove unsaved RAM was restored.
4. In A4 studio audition, choose the exact A4 output and enter all four actual
   track channels. Acknowledge the unqualified RAM-only trial and explicitly arm
   the A4 output. Arming resets confirmation controls: acknowledge the trial and
   manual reload again, then prepare the studio plan. If a capture or reconnect
   cleared the active candidate, select the same retained candidate again first;
   never regenerate merely to bypass stale-source or scope blockers.
5. Check track, CC number, wire channel, exact value and plan identity. Wire
   channels are 0-based; the configured controls are 1-based. Confirm only that
   exact plan. Any blocker ends this attempt: do not drop unsupported rows.
6. Send once. Record sent/expected counts, actual front-panel value and what
   you hear. DISARM remains reachable during delivery. No persistent save or
   automatic rollback is sent, including on partial or interrupted delivery.
7. DISARM, manually reload the source and listen/check the front panel. Receive
   a fresh baseline capture and compare it. Keep all untested controls locked.
8. Stop on mismatch, unexpected sound, wrong track, incomplete delivery or
   failed recovery. Preserve logs and dumps; do not retry automatically.

## Rytm And Favorites

Keep the existing one-Pad2 Rytm scratch/reload procedure separate. Test Sample
Bit Reduction on one pad only after the ordinary recovery test passes. A local
favorite is not an instrument save. Save promising versions manually to new
hardware slots, never immutable source slots, then retain fresh recaptures and
verify reloads before considering any of them for a show.
