# Synplant 2 UI References

Reference screenshots supplied on 2026-07-03 for the RytmRandomizer cockpit design thread.

## Files

- `synplant-2-main-genome-branches.png` - main genome view with four branches, mutation dots, seed controls, waveform preview, and action buttons.
- `synplant-2-dna-overview-sections.png` - DNA overview page dividing the sound model into Envelope/LFO, Oscillators, and Filter/effects sections.
- `synplant-2-dna-envelope-lfo-page.png` - detailed DNA page for Envelope and LFO controls with knobs and envelope/oscillation diagrams.
- `synplant-2-dna-oscillators-page.png` - detailed DNA page for Oscillators with A/B oscillator controls, waveform diagrams, and mix routing.
- `synplant-2-dna-filter-effects-page.png` - detailed DNA page for Filter and effects with filter, saturation, reverb, and adjustment controls.

## Design Use

Use these as visual inspiration for a simple RytmRandomizer cockpit UI: compact sound-shape visualization, grouped parameter families, reversible exploration, and clear preview/send safety states. Do not treat the screenshots as assets to clone pixel-for-pixel.
