# docs/archive/

Historical material moved here by WS-M1 (2026-05-18). **Safe to skip on first read** — none of these are contributor-onboarding.

Files in this directory document real decisions and milestones from past workstreams. They are preserved with full `git log --follow` history (moved via `git mv`, not copy+delete) so blame and authorship survive the relocation.

If you're looking for "where do I add X?" — read `../README.md` for the Active set, or jump straight to `../ARCHITECTURE.md` §6 ("Where to put new work").

## Categories

- **Codex briefs** (`CODEX_*`): the briefs handed to codex for the V1.34 modularization split. Work completed; briefs no longer load-bearing.
- **Collaborator-review intake** (`COLLABORATOR_REVIEW_*`, `COLLABORATOR_TRIAGE_*`): one-time intake / triage / checkpoint records for an external review packet.
- **Public-API hardening checkpoints** (`*_CHECKPOINT.md`, `*_PUBLIC_API_EXPORTS_*`): mid-flight progress markers from the explicit-`__all__` hardening pass.
- **Project identity** (`PROJECT_IDENTITY_*`): parked workstream (creative rename shortlist + companion plan).
- **Hardware manual inventory** (`HARDWARE_MANUAL_REFERENCE_INVENTORY.md`): pointers to personal Elektron manual files; not in-repo content.
- **Operator quickstarts** (`PASSIVE_CLI_OPERATOR_QUICKSTART.md`, `COLLABORATOR_QUICKSTART.md`): superseded by the active `README.md` + `CONTRIBUTING.md`.
- **Triage report** (`TRIAGE_REPORT.md`): the 2026-05-14 `docs/`-accuracy triage that originally pruned the directory.
