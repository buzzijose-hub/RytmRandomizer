# RytmRandomizer Music Library / Song Analysis Skill

This package contains a reusable skill for analyzing a music library, folder of songs, single reference track, live recording, or style target and converting the findings into mutation guardrails for the RytmRandomizer project.

Recommended local destination:

`<repo-root>\Skills\MusicLibraryGuardrails\`

Files included:

- `SKILL.md` — repeatable analysis process
- `Templates/MUSIC_ANALYSIS_GUARDRAILS_REPORT.md` — report template
- `Templates/mutation_guardrail_profile_template.json` — structured profile template

Suggested Git commit:

`git add .\Skills\MusicLibraryGuardrails`
`git commit -m "Add music library analysis guardrails skill"`
