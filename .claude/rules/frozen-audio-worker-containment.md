# Frozen Audio Worker Ownership

When changing the existing packaged analysis worker, apply
[the learned containment skill](../skills/learned/frozen-audio-worker-containment/SKILL.md).
Windows pipe stdin must not leave a blocking parent read that prevents spawned
child startup. Normalize child-origin signals to the existing categorical error
boundary; preserve real parent operator signals. Repeated cancellation must not
release ownership before terminal worker cleanup or permit late publication.

Require actual frozen-runtime evidence with developer paths removed and MIDI
disabled. Do not increase deadlines, grant hardware authority or replace the
worker framework to hide a startup failure. This rule is scoped to that existing
runtime and does not authorize background jobs, hardware access or user-file
cleanup.
