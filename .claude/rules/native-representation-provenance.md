# Native Representation And Source Provenance

- Treat exact native words, mathematical coordinates, forward device labels
  and wire scalars as separate representations. A colliding screen label is
  not an inverse identifier. Use parameter-specific canonical facts/helpers;
  never transfer A4 F1 conventions to F2 or Rytm LFO Depth.
- Keep stored candidate DTOs, protection wording and versioned sampling stable
  when only operator presentation changes. Exact replay compares more than raw
  IDs. Test old protected favorites as well as ordinary mutable sources.
- Validate source kind from canonical raw frames at every indexed/saved-state
  boundary. An A4 working `0x58` body may equal indexed `0x52` bytes, but that
  must not authorize source adoption, saved recapture or preflight, including
  an empty/fully locked candidate. Caller metadata is not authoritative.
- Protocol/storage versions are not installed firmware. Partial/coarse events
  do not establish exact native state, pending-edit freshness, atomicity or
  restoration. Static contracts and synthetic tests never grant hardware use.
- Preserve every unknown difference in experiment reports. Record origin,
  repeat/save/recovery separately; obtain query replies only through reviewed
  operator-present output boundaries, never from a passive report command.

Canonical owners and the bounded experiment are indexed in
`docs/NATIVE_REPRESENTATION_INTEGRATION.md`.
